## Setup
1. Clone the repo:
   ```sh
   git clone https://github.com/ElectroSheepH21/commander-gcody.git
   cd commander-gcody
   ```
2. Create and activate a virtual environment:
   
   Windows:
   ```sh
   python -m venv .venv
   .venv\Scripts\activate
   ```
   macOS/Linux:
   ```sh
   python3 -m venv .venv
   source .venv/bin/activate
   ```
3. Install dependencies:
   ```sh
   pip install -r requirements.txt
   ```
4. Run the application:
   
   Windows:
   ```sh
   python .\src\main.py
   ```
   macOS/Linux:
   ```sh
   python3 ./src/main.py
   ```
